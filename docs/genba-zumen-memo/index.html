現場写真に寸法・矢印・メモを入れて、かんたんに指示書PDFを作成できます。

1. 現場情報入力

現場名、住所、作業期間、責任者などを入れると、そのまま指示書に反映されます。

2. 入れる文字

文字を入れたい時は、先に下へ文字を書いてから「文字入力」を押してください。

入力する文字
使い方：1. 写真を追加 2. 文字入力または矢印・丸印・四角を選ぶ 3. 写真を押すか指でなぞる 4. 必要なら印を押したまま移動 5. PDF作成

3. 写真メモエリア

矢印・丸印・四角は、写真の上を指でなぞると入ります。

まずは写真を1枚選んでください
JPG・PNG・HEICに対応しています。
通常表示中。使いたいボタンを押してから写真を操作してください。

4. 操作ボタン

スマホで押しやすい大きさにしています。

5. PDFプレビュー

ここにA4縦の指示書イメージが表示されます。PDF作成ボタンでそのまま保存できます。
